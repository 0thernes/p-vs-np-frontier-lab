# Security Policy

<!-- SPDX-License-Identifier: CC-BY-4.0 -->

This repository contains pure mathematical formalizations (Lean 4.35.0), local exact-computation verification scripts (Python 3.13 + CaDiCaL 2.1.2), and LaTeX manuscript sources. It runs no network servers, stores no credentials or personal data, and processes only local deterministic inputs.

To report a soundness defect, definition-fidelity flaw, or build-script security issue, contact Alexander S. Donahue at `0_0@0thernes.art` or open an issue on the public repository with the finding class (`bug`, `error`, `issue`, `problem`, `dilemma`, or `conflict`).
